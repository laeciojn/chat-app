# Chat App

Chat em tempo real desenvolvido com Flask e Flask-SocketIO.

## Tecnologias

- Python
- Flask
- Flask-SocketIO
- HTML, CSS e JavaScript

## Instalação

```bash
git clone https://github.com/laeciojn/chat-app.git
cd chat-app
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

No Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

## Execução

```bash
python app.py
```

Acesse `http://127.0.0.1:5000` no navegador. Abra duas ou mais abas para testar as mensagens em tempo real.

## Estrutura

```text
chat-app/
├── app.py

```
